# ABRA Yazılım Birimi - Eğitimler ve Projeler

Bu repository, ABRA Yazılım Birimi kapsamında gerçekleştirilen eğitimleri, uygulamaları ve proje çalışmalarını içermektedir.

## Eğitim Kapsamı

* Ubuntu 22.04 LTS Kurulumu
* Algoritma Eğitimi
* Python ve C++ Eğitimi
* PyQt5 ve ZeroMQ
* Gömülü Sistemler
* Temel Havacılık
* OpenCV ile Görüntü İşleme
* Gazebo Simülasyon Ortamı
* ArduPilot ve SITL
* DroneKit ve PyMAVLink

## Geliştirme Ortamı

* İşletim Sistemi: Ubuntu 22.04.5 LTS
* Linux Kernel: 6.8
* Programlama Dilleri: Python, C++
* Sürüm Kontrol Sistemi: Git / GitHub

## Proje Düzeni

Her eğitim ve proje, ilgili klasörde kaynak kodları, açıklamaları, uygulama dosyaları ve gerekli ekran görüntüleriyle birlikte paylaşılacaktır.

## Amaç

Eğitimler kapsamında algoritma geliştirme, yazılım tasarımı, sistemler arası haberleşme, görüntü işleme ve otonom sistem simülasyonu alanlarında uygulamalı çalışmalar gerçekleştirmek.
